# 대본 쓰는 법

장소마다 파일이 하나씩 있습니다 (`harbor.txt` = 부두). 파일 이름이 곧 장소입니다.
장면은 파일 안에 적힌 **순서대로** 검사해서, 조건이 맞는 첫 장면이 나옵니다.
그래서 먼저 보여야 할 장면을 위에 둡니다. 다 본 장면은 다시 나오지 않습니다(`반복: 예` 제외).
맞는 장면이 하나도 없으면 "주변을 살핀다"가 나옵니다.

고친 뒤에는 이렇게 확인합니다.

```
python tools/story.py      # 대본 검사 + js/story.js 생성
```

`tools/release.py` 도 올리기 전에 이것을 먼저 돌리고, 오류가 있으면 멈춥니다.
**`js/story.js` 는 손으로 고치지 않습니다.** 대본에서 만들어지는 파일입니다.

## 장면 하나

```
=== 장면 h_deal
조건: 날 >= 5, 본 h_jabez
힌트: 사람 | 자베즈 — 그믐밤 배에 자리 하나
제목: 자베즈의 제안
그림: npc-jabez

노인이 배의 밧줄을 점검하고 있습니다. "나는 그믐 전에 뜰 거요."

그가 당신을 봅니다. "자리 하나는 비워두리다."

--- 선택: "자리를 남겨 주시오."
효과: 플래그 boatOffer, 정신력 +1
기록: 자베즈가 그믐밤의 배에 자리를 남겼다.
결과:
노인이 고개를 한 번 끄덕입니다.

--- 선택: "나는 남을 겁니다."
효과: 정신력 -1, 플래그 refusedBoat
결과:
노인은 한참 당신을 보다가 그물로 눈을 돌립니다.
```

- `=== 장면 이름` 으로 시작합니다. 이름은 영문·숫자·`_` 로, 겹치면 안 됩니다.
- 빈 줄로 나눈 덩어리가 화면에서 한 문단이 됩니다. 한 문단 안에서 줄을 바꾸면 띄어쓰기 한 칸으로 이어집니다.
- `#` 로 시작하는 줄은 메모입니다. 게임에 나오지 않습니다.

### 장면 머리에 쓸 수 있는 것

| 칸 | 뜻 |
|---|---|
| `조건:` | 이 장면이 나오는 조건 (아래 **조건** 참고). 없으면 항상 |
| `반복: 예` | 여러 번 나올 수 있음 |
| `조용: 예` | 지도에 "여기 뭐가 있다"고 표시하지 않음 (쉬는 장면) |
| `힌트: 태그 \| 글` | 지도에 적을 한 줄. 태그는 `핵심` `사람` `기록` `위험` |
| `기한: 8` | 그 날이 지나면 사라지는 장면이라고 지도에 표시 |
| `제목:` | 반드시 있어야 함 |
| `그림:` | `art/` 안의 그림 이름 (확장자 없이). 없으면 장소 그림 |
| `장소표시:` | 제목 아래 작은 글씨. 없으면 장소의 기본 설명 |
| `형식:` | `선택`(기본) · `판정 7` · `추격 cult` · `이야기` |
| `보정:` | 판정 장면의 추가 보정. 예: `보정: [소지품 match] 불빛 +1`, `보정: 재도전` |
| `문서:` | 장면을 열 때부터 보여줄 문서 (아래 **문서** 참고) |

### 형식

- **선택** — 본문 아래에 `--- 선택: 버튼 글씨` 를 여러 개 둡니다.
- **판정 7** — 주사위 두 개 + 관찰 보정이 7 이상이면 성공. `--- 성공` 과 `--- 실패` 를 둡니다.
  `보정: 재도전` 을 넣으면 실패할 때마다 다음 판정이 +1 씩 쉬워집니다(최대 +3). 핵심 단서를 판정으로 막을 때는 꼭 넣습니다.
- **추격 누구** — 본문이 추격 첫 화면의 글이 됩니다(비우면 추격자 기본 설명). 누구는 `cult` `towns` `gilman` `thing`.
  무사히 벗어났을 때 덧붙일 것이 있으면 `--- 탈출` 을 둡니다.
- **이야기** — 선택지 없이 "계속" 버튼 하나. 머리의 `효과:`·`기록:` 은 계속을 누를 때 적용됩니다.

### 선택지·성공·실패·탈출에 쓸 수 있는 것

| 칸 | 뜻 |
|---|---|
| `메모:` | 버튼 아래 작은 글씨 (선택지만) |
| `조건:` | 이 선택지가 보이는 조건 (선택지만). 탈출에서는 덧붙이는 조건 |
| `무게: 예` | 무거운 선택으로 표시 (선택지만) |
| `효과:` | 무엇이 바뀌는가 (아래 **효과** 참고). 여러 줄 가능 |
| `기록:` | 일지의 "지나온 일"에 남길 한 줄 |
| `문서:` | 결과와 함께 보여줄 문서 |
| `다음:` | 결과 뒤에 이어질 것. `추격 gilman 젖은 계단` 또는 `장면 l_silas_q`. 없으면 지도로 |
| `결과:` | 이 줄 아래부터 결과 글 |
| `분기: 조건` | 조건에 따라 결과가 갈릴 때. 위에서부터 맞는 첫 분기. 마지막은 `분기: 그 외` |

`결과:` 없이 `다음: 장면 …` 만 두면, 결과 글 없이 곧바로 그 장면으로 넘어갑니다.
선택지 공통의 `효과:` 를 먼저 적고, 분기마다 다른 것은 분기 아래에 적습니다.

`=== 하위장면 이름` 은 지도에서 직접 나오지 않고 `다음: 장면 이름` 으로만 불리는 장면입니다.

## 조건

쉼표로 나열하면 **모두** 맞아야 합니다. 앞에 `아님` 을 붙이면 반대입니다.

| 쓰는 법 | 뜻 |
|---|---|
| `단서 blood` | 그 단서를 얻었다 |
| `소지품 match` | 그 물건을 가지고 있다 |
| `플래그 marthaFled` | 그 일이 일어났다 |
| `본 i_confront` | 그 장면을 이미 보았다 |
| `밤` / `낮` | 지금 시간 |
| `날 >= 5` | 날짜 (첫날이 0, `그믐` 은 13). `>=` `<=` `>` `<` `=` |
| `주시 >= 2`, `탄약 < 6` | 주시, 남은 탄 |
| `인물 doctor` | 고른 탐사자 (`reporter` `doctor` `sailor`) |
| `의식준비` | 구절·때·자격을 모두 안다 |
| `준비된사람` | 당신 말고 걸어 들어갈 준비가 된 사람이 있다 |
| `확률 50` | 50% 확률 (분기에서만 쓰기) |

예: `조건: 날 >= 10, 본 i_confront, 아님 플래그 marthaFled`

## 효과

쉼표로 나열합니다. 줄 앞에 `[조건]` 을 붙이면 그 조건일 때만 적용됩니다.

| 쓰는 법 | 뜻 |
|---|---|
| `단서 flyer` | 단서를 얻는다 (`단서 @비밀` = 탐사자 각자의 비밀) |
| `소지품 match` / `버림 match` | 물건을 얻는다 / 잃는다 |
| `플래그 boatOffer` | 일이 일어났다고 적어 둔다 |
| `정신력 -2` `체력 +3` `주시 +1` `최대정신력 -1` `탄약 +2` | 수치 |
| `정신력 -주사위3` | 1~3 을 굴려서 뺀다. 굴린 값은 글에서 `{굴림}` |
| `정신력 -주사위4+1`, `체력 +3+치료` | 더하기로 이어 쓸 수 있다 (`치료` = 의사의 치료 솜씨) |

예: `효과: [소지품 gun] 탄약 +2`

조건은 모두 **선택한 순간의 상태**로 판단합니다. 효과를 적용한 뒤가 아닙니다.

## 글 안에 넣는 것

| 쓰는 법 | 뜻 |
|---|---|
| `[조건] 문단` | 문단 맨 앞에 두면, 조건이 맞을 때만 그 문단이 나온다 |
| `{만약 조건:글}` | 조건이 맞을 때만 그 글. 콜론 뒤 글자는 띄어쓰기까지 그대로 들어간다 |
| `{아니면:글}` | 바로 앞의 `{만약 …}` 이 틀렸을 때의 글 |
| `{부름}` | 마사가 탐사자를 부른 이유 (탐사자마다 다름) |
| `{재회}` | 카터가 탐사자를 알아보는 말 (탐사자마다 다름) |
| `{비밀단서}` | 탐사자 비밀 단서의 본문 |
| `{꿈}` | 무작위 꿈 한 토막 |
| `{굴림}` | 효과에서 굴린 값 |
| `{3+치료}` | 계산한 숫자 |

## 문서

```
문서: 실종자 수배
> 메리 휘트필드 · 당시 11세
> 토머스 "늙은 톰" 개럿 · 당시 63세
>
> 소식을 아시는 분은 마을 사무소로
```

`>` 로 시작하는 줄이 문서의 한 줄입니다. `>` 만 있으면 빈 줄입니다.

## 검사기가 잡아내는 것

- 없는 단서·물건·추격자·탐사자·그림·장면 이름 (오타)
- 어디서도 세우지 않는 플래그를 조건에서 읽는 것 (오타이거나 끊긴 이야기)
- 세우기만 하고 아무도 읽지 않는 플래그 (경고만)
- 결과도 다음도 없는 선택지, 성공·실패가 빠진 판정, `{아니면}` 앞에 `{만약}` 이 없는 것
- 모르는 칸 이름
