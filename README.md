# 심연의 일지 — 블랙포인트 사건

1927년 가을, 매사추세츠 북부 해안. 백 년째 제물을 바쳐온 항구 마을에서
그믐밤에 누가 값을 치를지 알아내는 조사 게임.

## 휴대폰에 설치하기

1. 인터넷이 될 때 이 페이지 주소를 한 번 엽니다.
2. 첫 화면에 **"✓ 이 기기에 저장됨"** 이 뜰 때까지 기다립니다 (5MB 정도).
3. 홈 화면에 추가합니다.
   - 아이폰: 사파리 아래쪽 공유 버튼(□↑) → **홈 화면에 추가**
   - 안드로이드: 크롬 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
4. 이제 홈 화면 아이콘으로 열면 인터넷 없이도 플레이할 수 있습니다.

## 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀 |
| `css/style.css` | 색·글꼴·배치 |
| `js/data.js` | 장소, 단서, 추론, 인물, 결말 문장, 지도 힌트 |
| `js/engine.js` | 상태, 화면 그리기, 주사위, 추격 |
| `js/turn.js` | 턴 진행, 추론 발동, 젖은 발자국, 재방문 |
| `js/scenes.js` | 장소 12곳의 모든 장면 |
| `js/finale.js` | 그믐밤, 결말, 게임 시작 |
| `js/pwa.js` | 휴대폰 설치 안내와 오프라인 저장 등록 |
| `sw.js` | 오프라인 저장 (목록은 `tools/release.py` 가 만든다) |
| `art/` | 삽화 |
| `icons/` | 홈 화면 아이콘 |

스크립트는 위 순서대로 불러야 합니다. 모두 같은 전역 공간을 씁니다.

## 고치고 올리는 법

```
python tools/convert_art.py   # 새 그림을 넣었을 때만
python tools/release.py       # 버전을 올리고 오프라인 저장 목록을 갱신
git add -A
git commit -m "무엇을 고쳤는지"
git push
```

1~2분 뒤 사이트에 반영되고, 휴대폰은 인터넷이 될 때 한 번 열면 새 버전으로 바뀝니다.

## 로컬에서 확인할 때

`localhost` 에서는 오프라인 저장(서비스 워커)이 꺼져 있습니다. 고친 파일 대신 저장본이 뜨는 일을 막기 위해서입니다.
오프라인 동작까지 확인하려면 주소 끝에 `?sw` 를 붙이세요.

## 진행 저장

지도 화면으로 돌아올 때마다 자동 저장됩니다(`localStorage` 의 `bp_save_v1`). 장면 도중에는 저장하지 않습니다.
첫 화면에 **이어하기** 가 뜨고, 결말을 보면 저장이 지워집니다.
